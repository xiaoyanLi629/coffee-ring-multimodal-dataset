# Manuscript figures

Every figure in `manuscript/` is generated by code in this folder; nothing is laid out by hand.
Run from the project root:

```bash
python figures_src/make_all.py          # all four figures
python figures_src/make_all.py fig2     # one figure
```

Output goes to `manuscript/figures/` as a vector PDF (used by `manuscript.tex`) and a 300 dpi PNG for preview.
Fonts are embedded as TrueType, so text in the PDFs stays editable.

| Script | Output | Content |
|---|---|---|
| `fig1_coffee_ring.py` | `water.pdf` | Coffee-ring schematic, drawn entirely in code |
| `fig2_setup.py` | `zutu.pdf` | Setup and imaging of one deposit (condition E, droplet 2) |
| `fig3_data_overview.py` | `data_overview.pdf` | Eight droplets × five modalities, read from `data/` |
| `fig4_ssim.py` | `analysis2.pdf` | SSIM and feature distributions, from `data/features/` |

`style.py` holds everything shared: figure widths (180 mm and 88 mm, Scientific Data), font (Arial 7 pt, panel letters 8 pt bold), colours and paths.
Each figure script starts with a parameter block (samples, crops, label positions, magnifier coordinates), so most changes only touch those lines.

`assets/` holds the two images that cannot be generated: the autosampler drawing and the photograph of the environmental chamber, both extracted at their original resolution from the earlier PowerPoint files. Replace them with better originals if available; the code does not need to change.

Notes:

- Scale bars are off by default (`SCALE_UM_PER_PX` in `fig2_setup.py`). The SEM metadata gives magnification (50×) but no pixel size, and the optical microscope has no calibration on record, so no bar is drawn until a calibrated value is available.
- In `fig4_ssim.py` the two frequency energies are min–max rescaled for display only, exactly as in the earlier `experiment/generate_figure3.py`.
- Requires matplotlib, numpy, pandas, scipy and Pillow. On the AutoDL server: `/root/autodl-tmp/coffee-env/bin/python`.
